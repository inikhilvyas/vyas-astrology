# VYAS Classical Astrology Knowledge Library / शास्त्रीय ज्योतिषागार

This directory is the dedicated repository for Classical & Research Astrology Books (PDFs / Texts).

## How to use / उपयोग कैसे करें:
1. **Add your PDF books here**: Simply copy or drop your astrology books (PDF format) into this `books/` folder.
   - Examples:
     - `Laghu_Parashari.pdf` (लघु पाराशरी)
     - `Phaladeepika.pdf` (फलदीपिका)
     - `Brihat_Parashara_Hora_Shastra.pdf` (बृहत्पाराशर होराशास्त्र)
     - `Saravali.pdf` (सारावली)
     - `Jataka_Parijata.pdf` (जातक पारिजात)
     - `Uttara_Kalamrita.pdf` (उत्तर कालामृत)
     - `KP_Readers_1_to_6.pdf` (केपी रीडर्स)
2. **Automated Ingestion & Search**:
   - The VYAS system automatically indexes all PDFs placed in this folder using `pdfplumber`.
   - In the VYAS application under the **"Classical Library & Books (शास्त्रीय ग्रंथागार)"** tab, you can:
     - View all loaded books and total pages.
     - Search across all books for any Sanskrit/Hindi/English astrological query (e.g. `मारकेश`, `दशा`, `राजयोग`, `कारकांश`, `अष्टकवर्ग`).
     - Directly extract shlokas, commentary, and predictive principles.
     - Upload new books directly via the web interface.
