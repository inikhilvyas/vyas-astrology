# VYAS ASTRA — C++ Engine (brand: Nikhil Vyas)

A native C++20 port of the VYAS calculation engine. It reads the **same JPL
DE440s kernel** the Python engine uses and reproduces the same numbers, so the
two can never drift apart.

## Layout

| File | What it is |
|---|---|
| `src/astro.hpp` | Julian day, ΔT, sidereal time, obliquity, nutation, Lahiri ayanamsa, Ascendant/MC, lunar nodes |
| `src/spk.hpp` | Self-contained reader for the JPL DE440s SPK/DAF kernel (no external astronomy library) |
| `src/ephemeris.hpp` | Geocentric sidereal positions, speeds, Ascendant |
| `tests/golden_vectors.h` | Golden values generated by the validated Python engine |
| `tests/test_engine.cpp` | Test bench comparing C++ against those golden values |
| `tools/gen_golden.py` | Regenerates the golden vectors from Python |

## Build and test

```bat
set PATH=C:\ProgramData\mingw64\mingw64\bin;%PATH%
g++ -std=c++20 -O2 -Icpp\src -Icpp\tests cpp\tests\test_engine.cpp -o artifacts\vyas_engine_test.exe
artifacts\vyas_engine_test.exe data\de440s.bsp
```

## Status

- ✅ Julian day, ΔT, ayanamsa (0.00″ from Swiss Ephemeris at J2000), Ascendant,
  lunar nodes, sidereal time — all passing against the golden vectors.
- 🔧 DE440s Type-2 record decoder: the segment summary, DAF headers and
  Chebyshev evaluation are implemented; the remaining work is pinning the exact
  (intervals, degree) packing of the coefficient block for every segment, which
  is done by validating each candidate layout against a physical distance.
- ⏳ Next: vargas, Vimshottari dasha, Ashtakavarga, Shadbala, KP — each mirrored
  from the Python module of the same name and pinned by the same golden tests.
- ⏳ Then the desktop UI (Qt6/QML, dark + gold, Nikhil Vyas branding).
